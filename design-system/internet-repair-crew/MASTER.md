# Midnight Relay interface

The UI UX Pro Max query for “interactive motorsport editorial industrial” returned a high variance brutalist direction. Use its hard edges, visible grid, and asymmetric composition with a graphite and safety orange palette drawn from the motorsport brief. Use two type stacks: heavy system sans for voice and a system monospace for archive labels.

| Role | Value |
| --- | --- |
| Background | `#121416` |
| Working surface | `#1a1d20` |
| Text | `#f0eee7` |
| Secondary text | `#b0b4b6` |
| Action and attention | `#ff7943` |
| Text on action | `#171411` |

Use the orange for the active repair and the main action. Cyan, amber, and mint identify Patch, Fetch, and Set, with their names visible next to each color. Keep information stable while fragments move. Use large touch targets, visible focus, no hover dependency, and a complete motion-free version.
